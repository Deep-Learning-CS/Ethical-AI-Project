# UNLP 2025 Shared Task - Subtask 2: Span Detection

This branch contains the work for Subtask 2 (Span Identification) of the UNLP 2025 Shared Task on Detecting Social Media Manipulation, part of the Ethical-AI-Project.

## Goal

The objective is to identify and extract the specific spans of text within Ukrainian Telegram posts that contain manipulative language or techniques.

## Status

Work in progress. Contains implementation for model training and basic setup.
